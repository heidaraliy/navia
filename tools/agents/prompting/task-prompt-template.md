# Task Prompt Template

Use this shape when delegating work to another agent.

```text
Role: <explorer | planner | worker | reviewer>
Goal: <concrete outcome>
Read scope: <paths or docs>
Write ownership: <paths, or "none">
Do not touch: <paths or behaviors>
Skills/instructions: <required Navia skills and instruction files>
Validation/output: <commands to run or exact response format>
```
